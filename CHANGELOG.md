# StressLess Student AI — Changelog

### Added
- AI Wellness Coach powered by Google Gemini 1.5 Flash
- Daily Mood Tracker with 6 emotion states
- Stress Trigger Analysis with 12 predefined triggers + custom input
- Reflection Journal with 3 daily prompts and streak tracking
- Wellness Score Engine (0-100 weighted score)
- Personalized Study Wellness Planner with AI-generated plans
- Emergency Calm Mode (4-7-8 breathing + 5-4-3-2-1 grounding + affirmations)
- Progress Dashboard with Chart.js visualizations
- AI Exam Crisis Detector with two-level severity detection
- Glassmorphism dark theme design system
- Full mobile responsiveness with bottom navigation
- WCAG AA accessibility compliance
- LocalStorage persistence layer
- Service Worker for basic PWA support
- Crisis helpline integration (iCall, Vandrevala, NIMHANS)
- Fallback responses for offline/no-API-key scenarios
- XSS prevention through input sanitization
- API key protection via .gitignore
